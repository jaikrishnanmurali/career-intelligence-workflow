# Claude Code guidance

Start Claude Code from the Career Ops root and follow its `AGENTS.md` before using this extension. The installed `/career-intelligence` adapter points to this repository’s canonical skill.

Career Ops remains the career and application system. Career Intelligence schedules its official structured scanner, adds supplemental feeds and rolling ATS boards, can normalize verified alerts from eight broader job platforms, and sends private digests. Smart Digest may add a bounded Claude Code cloud step. Never imply that Discovery signs into or directly crawls LinkedIn, Indeed, Glassdoor or every careers page; an alert lead still needs a complete live specification.
